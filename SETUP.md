# Настройка и запуск проекта

## Обзор системы

Ваш проект уже имеет полную JWT аутентификацию и систему заказов! Вот что было реализовано:

### ✅ Backend (уже готов):
- **JWT аутентификация** с access/refresh токенами
- **Система заказов** с созданием и просмотром истории
- **Корзина** с backend API
- **Оплата** через Stripe
- **База данных** PostgreSQL с полной схемой

### ✅ Frontend (добавлено):
- **Контексты аутентификации и корзины**
- **Модальные окна** входа и регистрации
- **Интегрированная корзина** с backend API
- **Оформление заказов** с итоговой суммой
- **История заказов** с пагинацией
- **Навбар** с пользовательским меню

## Настройка переменных окружения

### Backend (.env в папке server):
```env
NODE_ENV=development
PORT=5000
SECRET=your_jwt_secret_key
REFRESH_SECRET=your_refresh_secret_key
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
STRIPE_SECRET_KEY=your_stripe_secret_key
OAUTH_CLIENT_ID=your_google_oauth_client_id
OAUTH_CLIENT_SECRET=your_google_oauth_client_secret
```

### Frontend (.env в папке client):
```env
VITE_API_URL=http://localhost:5000
```

## Запуск проекта

### 1. Backend:
```bash
cd server
npm install
npm run dev
```

### 2. Frontend:
```bash
cd client
npm install
npm start
```

## Функциональность

### Аутентификация:
- Регистрация новых пользователей
- Вход в систему
- Автоматическое обновление токенов
- Выход из системы

### Корзина:
- Добавление товаров в корзину (требует авторизации)
- Изменение количества товаров
- Удаление товаров
- Синхронизация с backend

### Заказы:
- Оформление заказа с итоговой суммой
- Выбор способа оплаты (Stripe)
- Просмотр истории заказов
- Пагинация заказов

### Навигация:
- Главная страница с меню
- Корзина (модальное окно)
- История заказов (/orders)
- Пользовательское меню

## API Endpoints

### Аутентификация:
- `POST /auth/signup` - регистрация
- `POST /auth/login` - вход
- `POST /auth/refresh` - обновление токена
- `POST /auth/logout` - выход

### Корзина:
- `GET /cart` - получить корзину
- `POST /cart/add` - добавить товар
- `POST /cart/increase` - увеличить количество
- `POST /cart/decrease` - уменьшить количество
- `POST /cart/remove` - удалить товар

### Заказы:
- `POST /orders/create` - создать заказ
- `GET /orders` - получить заказы пользователя
- `GET /orders/:id` - получить конкретный заказ

### Оплата:
- `POST /payment` - создать платеж Stripe

## Структура базы данных

- **users** - пользователи
- **cart** - корзины пользователей
- **cart_item** - товары в корзине
- **orders** - заказы
- **order_item** - товары в заказе
- **products** - товары
- **resetTokens** - токены сброса пароля

## Безопасность

- JWT токены с коротким временем жизни (60s)
- Refresh токены для обновления
- Хеширование паролей с bcrypt
- Валидация входных данных
- CORS настройки
- Helmet для безопасности заголовков

## Тестирование

Для тестирования системы:

1. Запустите backend и frontend
2. Откройте http://localhost:3000
3. Зарегистрируйтесь или войдите
4. Добавьте товары в корзину
5. Оформите заказ
6. Проверьте историю заказов
